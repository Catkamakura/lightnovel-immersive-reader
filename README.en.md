# 轻读 · LightNovel Immersive Reader

> 🤖 **This project is a 100% vibe-coding experiment**: every line of code, all docs and tests — and the demo video below (recording, on-screen guidance, editing, narration and bilingual subtitles) — were generated by **Claude Opus 4.8** and **Claude Fable 5**.

Reading on [www.lightnovel.fun](https://www.lightnovel.fun) usually means forum-style markup, a click for every chapter, and progress that vanishes the moment you close the tab. This is a single-file **Tampermonkey / Violentmonkey userscript** that layers a clean, Google-Docs-style immersive reader over the live site — nothing on the original page is replaced or modified. It talks to the site's own web API and re-presents the content: web novels scroll seamlessly from chapter to chapter, your place is always remembered, and any book is one click away from a proper EPUB/TXT export or a fully-tagged import into your **Calibre** library.

> 📥 **One-click install**: get [Tampermonkey](https://www.tampermonkey.net/) or [Violentmonkey](https://violentmonkey.github.io/), then click **[📖 Install](https://raw.githubusercontent.com/Catkamakura/lightnovel-immersive-reader/main/lightnovel-immersive-reader.user.js)**.
>
> ⚠️ Desktop only for now.

## Features

- **Read** — web novels scroll seamlessly, Qidian-style: past a chapter's end straight into the next, upward into the previous. Chapters are prefetched in the background so the boundary never waits, and a floating chip keeps you oriented (`chapter · 第 i / N 章 · ~book %`). Prefer pages? One toggle brings back the classic chapter-per-page reader.
- **Navigate** — a Google-Docs-style outline on the left follows along as you read; an optional Sublime-style minimap on the right maps the loaded chapters in detail, with ↑/↓ caps counting what lies beyond — click anywhere on it to jump. Books pasted as one giant post are auto-split using their in-text table of contents, and you can adjust the splits by hand.
- **Remember** — click any paragraph to bookmark it (kept per chapter); web novels resume at your last chapter and position, single posts at the last scroll spot. Progress is stored per account and exports to a file for moving between devices.
- **Keep** — one-click **EPUB** (cover + embedded images; EPUB3 by default, epubcheck-clean, EPUB2 fallback) or **TXT**, with a selectable chapter range — or push the book straight into a Calibre-Web-Automated library via the optional [`calibre-bridge`](calibre-bridge/) *(experimental)*.
- **Comfort** — paper/sepia/night themes, follow-system dark mode or a custom background color; font, size, spacing and width all adjustable; the UI speaks **English and 中文**; credits (author / illustrator / translator / …) are parsed from the front matter into the EPUB metadata, with an optional LLM tidy-up *(experimental)*; and an 11-step guided tour lives in settings whenever you forget where something is.

## EPUB output

The reader builds a real **EPUB3 by default** (the current standard) — verified **epubcheck-clean (0 errors)**:

- MARC relator roles via `<meta refines property="role" scheme="marc:relators">`
- series via `belongs-to-collection` (plus `calibre:series` for Calibre)
- a proper XHTML Navigation Document (`<nav epub:type="toc">`, manifest `properties="nav"`)
- `dcterms:modified` release identifier and a cover marked `properties="cover-image"`

An **EPUB2 fallback** is available for older devices/readers (settings → **下载 EPUB 版本**). Images that can't be embedded are dropped so the EPUB is always self-contained, and LightNovel's custom `img-width` / `img-height` attributes are stripped. The optional bridge's `enrich_epub` is **version-aware**: refines for EPUB3, `opf:role` attributes for EPUB2.

## Install

1. Install a userscript manager: **[Tampermonkey](https://www.tampermonkey.net/)** or **[Violentmonkey](https://violentmonkey.github.io/)**.
2. Click **[📖 Install](https://raw.githubusercontent.com/Catkamakura/lightnovel-immersive-reader/main/lightnovel-immersive-reader.user.js)** and your manager pops up its install page — or paste [`lightnovel-immersive-reader.user.js`](lightnovel-immersive-reader.user.js) into a new userscript.
3. Open any page on `https://www.lightnovel.fun/` — that's it. The script auto-updates from this repo.

It only requests `GM_xmlhttpRequest`, and `@connect`s to `lightnovel.fun`, `127.0.0.1` / `localhost` (the optional bridge), and your chosen LLM host. No secrets ship with the code — API keys and the bridge token are entered at runtime in settings.

## Quick use

- On a **detail or list page**, click **📖 沉浸阅读** (list cards get a small **📖** of their own).
- Hover the **top-left corner** and the controls slide out: **☰** outline, **⤓** download (appears for books worth exporting), **⚙** settings + the guided tour.
- Click the **✕ 退出** pill (bottom-right) or press **Esc** to leave — the site lands on the chapter you were reading.

## Experimental / at your own risk

Two parts of the project are **experimental** and connect to **external services** — use them at your own risk:

- **calibre-bridge integration** — the **发送到书库 (Calibre)** setting (collapsed by default, tagged 实验性) and the cross-origin `@connect` to the local bridge.
- **LLM metadata** — the **LLM 整理元数据** setting (collapsed by default, tagged 实验性) and the `@connect` to LLM hosts (`api.deepseek.com` / `api.kimi.com` / `api.openai.com` / `api.moonshot.cn`). This may **incur cost**.

In both cases your **API keys / bridge token live in the browser's localStorage**. Understand what you're enabling before turning these on.

## Optional: send to your Calibre library

> **Experimental** — see the note above.

The reader can POST the EPUB you just read into a **Calibre-Web-Automated (CWA)** library via the [`calibre-bridge/`](calibre-bridge/) FastAPI companion, which enriches the OPF metadata (title, author, translator, series + volume, identifiers, cover, tags) and drops the file into CWA's ingest folder. **Import only** — no progress/bookmark sync.

```bash
cd calibre-bridge
cp .env.example .env          # optional: set a BRIDGE_TOKEN
docker compose up -d --build
```

This scaffolds both CWA (web UI at `http://localhost:8083`) and the bridge (`http://127.0.0.1:8788`). Then in the reader open **设置 → 发送到书库**, tick *启用书库*, and the download dialog gains a **📚 发送到书库** button. See [`calibre-bridge/README.md`](calibre-bridge/README.md) for remote/Tailscale setups and the API.

## Develop / verify

The reader is a single vanilla-JS file with no build step. Verification runs headless via Playwright:

```bash
npx playwright install chromium    # one-time: install the browser
npm run verify                     # verify-userscript.mjs (32 checks)
npm run verify:webnovel            # seamless flow + paged fallback (12 checks)
npm run verify:lib                 # send-to-library path
```

The bridge has its own Python tests (`uv run pytest` inside `calibre-bridge/`).
